# SafaiSetu

**AI-assisted garbage complaint tracking for colonies and small cities.**

SafaiSetu is a web application built to help residents report garbage-related issues and track complaints, with the goal of supporting cleaner communities.

## Getting Started

First, install the project dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.

You can start editing the application by modifying `src/app/page.js`. The page automatically updates as you edit the file.
